#  MYVIDEO

A full-stack real-time video conferencing application that allows users to create and join meetings with secure authentication. The platform supports video and audio calls, real-time chat, screen sharing, and participant management, delivering a seamless online meeting experience.

## Features

* User Authentication
* Create & Join Meetings
* Video & Audio Calling
* Real-Time Chat
* Screen Sharing
* Participant Management
* Responsive Design

## Tech Stack

* Frontend: React, Vite, Tailwind CSS
* Backend: Node.js, Express.js
* Database: MongoDB
* Real-Time Communication: Socket.io
* Authentication: JWT

## Getting Started

```bash

# Install dependencies
npm install

# Start the  backend
npm run dev

# Install dependencies
npm install

# Start the frontend 
npm start
```
